# Building the PDF

No LaTeX installation required. [Tectonic](https://tectonic-typesetting.github.io)
is a single binary that downloads the packages it needs on first run.

```
tectonic -X compile main.tex --outdir .
```

Produces `main.pdf`. Rerun passes and BibTeX are handled automatically.

## Three things the class needs, and why

Each cost a failed compile, so they are recorded rather than left for the next
person to rediscover.

1. **`pdflatex` class option.** Without it `sn-jnl` loads `breakurl`, which
   emits PostScript specials and fails under any engine that writes PDF
   directly — pdflatex, xelatex, lualatex, tectonic. The template's own
   preamble comments say so; it is easy to read past.

2. **`\usepackage{manyfoot}`.** The class installs a footnote hook at
   `\begin{document}` and halts with an undefined control sequence without it.
   It is in the template's preamble and looks optional. It is not.

3. **Table footnotes go inside a group, not after `\[2pt]`.** A `\` after
   `\end{tabular}` raises *"There's no line here to end"*; `{\footnotesize
   ...}` on its own line works.
