consider robust scaling and winsorization/capping of extreme values.
     These columns show heavy right skew and many outliers (especially V3–V7), 
which can distort linear models and distance-based methods.
  • V5, V6, V7 → Create ratio and difference features such as V5/V6, V5/V7, 
V6/V7, and pairwise spreads between these lab-like measurements.
     The three variables have very different ranges and many outliers, so 
relative comparisons may capture physiology better than raw levels.
  • V8, V9, V10 → Try polynomial or spline terms, and interactions with V3–V7; 
keep a standardized version for linear models.
     These variables are more compact and less outlier-prone, so they may serve
well as smooth nonlinear covariates or interaction partners.
  • V1 → Treat as a continuous age-like feature and test nonlinear bins or 
splines (e.g., decades or restricted cubic splines).
     V1 spans 4 to 90 with a broad central mass, suggesting age effects may be 
nonlinear.
  • All numeric columns → Add missingness indicators only if any missingness 
appears later in the pipeline; otherwise keep a clean numeric matrix and 
standardize for linear models.
     Current analysis shows no missing values, so the main benefit comes from 
stable scaling rather than imputation features.

⚠ Pitfalls
  • Exact duplicate rows (13 duplicates, 2.2%)
     → Verify whether duplicates are legitimate repeat measurements; if not, 
deduplicate before splitting or use a group-aware split so identical rows do 
not leak across train/test.
  • Potential target leakage from random splitting with duplicates
     → Use a deduplicated dataset or a split strategy that prevents 
near-identical records from appearing in both train and test; otherwise 
held-out evaluation can be overly optimistic.
  • Class imbalance (Class 1 about 71%, Class 2 about 29%)
     → Use stratified splits, report balanced metrics such as 
F1/ROC-AUC/PR-AUC, and consider class weights or threshold tuning if the 
minority class is the key outcome.
  • Heavy skew and outliers in several predictors (especially V3–V7)
     → Prefer robust preprocessing, transformations, and tree-based baselines; 
avoid assuming Gaussian behavior or relying on unscaled raw values for 
linear/distance-based models.
  • Small sample size (583 rows)
     → Use cross-validation, keep model complexity controlled, and compare 
against simple baselines to reduce overfitting risk.
  • Possible ambiguity in column semantics (generic names V1–V10)
     → Map columns to domain meaning if possible, because feature engineering 
and interpretation are much safer when you know which measurements are related.
