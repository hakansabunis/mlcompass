indicators only if future missing data appears
     Current data have no missing values, but scaling will help logistic 
regression and related baselines on V1–V10.

⚠ Pitfalls
  • Duplicate rows (13 exact duplicates, 2.2%)
     → Verify whether duplicates are legitimate repeated measurements; if not, 
remove duplicates before splitting or use group-aware splitting to avoid 
train/test leakage.
  • Class imbalance (Class 1: 71.4%, Class 2: 28.6%)
     → Use stratified splits, emphasize balanced metrics such as 
F1/ROC-AUC/PR-AUC, and consider class weights or threshold tuning.
  • Small dataset size (583 rows)
     → Prefer simpler models and nested or repeated cross-validation; keep 
hyperparameter search conservative to reduce overfitting.
  • Outlier-heavy numeric features (especially V3, V4, V5, V6, V7)
     → Inspect extreme values for data-entry issues, and test robust 
preprocessing such as log transforms, winsorization, or tree-based models.
  • Potential target leakage from preprocessing done before splitting
     → Fit encoders, scalers, imputers, and any outlier handling only on 
training folds within a pipeline.
