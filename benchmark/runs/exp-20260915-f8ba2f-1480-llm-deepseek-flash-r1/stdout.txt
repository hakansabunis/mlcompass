⚠ Pitfalls
  • 13 exact duplicate rows (2.2%)
     → Confirm duplicates are genuine repeated observations; if not, 
de-duplicate before splitting or use GroupKFold by duplicate group to avoid 
train/test leakage.
  • Class imbalance (Class 1: 71.4%, Class 2: 28.6%)
     → Use stratified splits, class_weight='balanced' or scale_pos_weight, and 
evaluate with AUC, F1, and recall rather than accuracy alone.
  • Heavy right-skew and IQR outliers in V3-V7
     → Tree models are robust; for linear/SVM use log1p and robust scaling, and
cap only if values are confirmed data errors.
  • Small sample size (583 rows, 10 features)
     → Use repeated cross-validation, regularize aggressively, avoid 
high-capacity models, and report uncertainty (e.g., confidence intervals).
  • Gender imbalance (441 Male vs 142 Female)
     → Stratify by V2, evaluate performance per gender subgroup, and check 
whether model behavior differs across groups.
