  • V1 → Try robust scaling and bucketed versions (e.g., quantile bins) of V1
     V1 is numeric with a right tail and a few outliers (min 0, max 74, 
outliers flagged), so nonlinear or binned representations may be more 
informative than raw values alone.
  • V2 → Consider log1p transform or robust scaling for V2
     V2 shows clear outliers and a skewed spread (outliers flagged, max 50 vs 
median 4), so a transformed version may improve linear and distance-based 
models.
  • V3 → Consider log1p transform and/or winsorization for V3
     V3 has the strongest scale and outlier pattern (250 to 12500, many 
outliers flagged), so compressing extreme values can help stabilize model 
training.
  • V4 → Use V4 as-is, but also test simple threshold/binned features
     V4 is numeric with no outliers flagged and a relatively compact range (2 
to 98), but coarse bins may still capture nonlinear effects on the target.
  • V1, V2, V3, V4 → Add cross-feature interactions such as V1/V2, V3/V2, 
V1*V4, and V2*V4
     All predictors are numeric and likely encode related blood donation 
history; interaction terms can help linear models capture joint effects present
across V1-V4.
  • V1, V2, V3 → Create ratio or recency-style composites if domain semantics 
allow it, and test rank-based transformations
     The variables appear to be related donation-count/volume/time features, 
and the different scales in V1-V3 suggest derived composite features may better
expose structure.

⚠ Pitfalls
  • Exact duplicate rows are common (215 duplicates, 28.7% of the data)
     → Verify whether duplicates are genuine repeated observations; if not, 
deduplicate before splitting or use a group-aware split so identical rows 
cannot leak across train and test.
  • Potential train-test leakage from random splitting with duplicates
     → Perform deduplication or split on a stable entity/group key if 
available, and keep all copies of a duplicated record within the same fold.
  • Class imbalance in the target (Class 1 about 76%, Class 2 about 24%)
     → Use stratified splits, class weights or balanced loss, and evaluate with
imbalance-aware metrics such as ROC-AUC, PR-AUC, recall, and F1 rather than 
accuracy alone.
  • Small dataset size (748 rows) increases variance and overfitting risk
     → Prefer simple baselines first, use cross-validation, limit model 
complexity, and tune conservatively to avoid fitting noise.
  • Several numeric features have strong outliers and skew (especially V2 and 
V3)
     → Use robust preprocessing, inspect whether extreme values are valid, and 
compare raw, log-transformed, and winsorized versions during validation.
