⚠ Pitfalls
  • Duplicate rows present (13 exact duplicates, 2.2% of data)
     → Verify whether duplicates are true repeated records; if not, remove them
before splitting, or use grouped splitting to keep duplicates in the same fold.
  • Class imbalance in the target (Class 1: 71.4%, Class 2: 28.6%)
     → Use stratified splits and metrics suited to imbalance (e.g., F1, 
balanced accuracy, ROC-AUC/PR-AUC), and consider class weights or threshold 
tuning.
  • Strong outliers and skew in several numeric predictors (especially V3, V4, 
V5, V6, V7)
     → Prefer robust preprocessing (log transforms, winsorization, robust 
scaling) and compare against tree-based models that are less sensitive to raw 
scale.
  • Small sample size for a binary classification problem (583 rows)
     → Use cross-validation rather than a single train/test split, keep models 
simple where possible, and avoid overly complex feature engineering that can 
overfit.
