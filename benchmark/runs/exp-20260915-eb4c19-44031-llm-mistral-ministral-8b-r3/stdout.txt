🔧 Feature engineering
  • Latitude,Longitude → Create distance_to_coast feature (e.g., using 
Euclidean distance to nearest coast boundary) or bin into coastal/non-coastal 
categories.
     Geospatial proximity may correlate with price (e.g., coastal properties 
often command higher prices).
  • AveRooms,AveBedrms → Derive `rooms_per_bedroom` ratio (AveRooms/AveBedrms) 
or flag extreme values (e.g., >10 rooms/bedroom) as potential outliers.
     Non-linear relationships between rooms and bedrooms may exist; ratios can 
capture efficiency metrics.
  • Population → Apply log transformation or bin into population density 
categories (e.g., low/medium/high).
     Highly skewed distribution (IQR outliers) suggests non-linear impact on 
price; log scaling or binning may improve model fit.
  • AveOccup → Flag unrealistic values (e.g., >5 occupants per bedroom) or 
create a binary feature for high-density units.
     Extreme outliers (e.g., 1243 occupants) likely indicate data errors or 
anomalies; filtering or binning may help.
  • MedInc → Bin into income quartiles or interact with `Latitude` (e.g., 
high-income coastal areas).
     Income is a strong predictor of housing prices; binning may capture 
non-linear effects better than raw values.

⚠ Pitfalls
  • Censored/capped target (`price` at 1.79176 with 4.7% of data)
     → Validate if `price` is truly capped (e.g., survey limits) or treat as 
missing data. Use robust regression (e.g., Huber loss) or censored regression 
models.
  • Outliers in `AveRooms`, `AveBedrms`, `Population`, and `AveOccup`
     → Apply winsorization (capping extreme values at P99) or use robust 
scaling (e.g., median/IQR) to mitigate influence on models.
  • No explicit target encoding or validation split
     → Use stratified sampling (if class imbalance exists) or time-based splits
(if temporal data) to ensure robust evaluation.
  • Geospatial features (`Latitude`, `Longitude`) not leveraged for spatial 
patterns
     → Explore kernel density estimation or spatial clustering (e.g., DBSCAN) 
to identify price clusters or hotspots.
